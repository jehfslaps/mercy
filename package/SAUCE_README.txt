SAUCE  -  teaser build (private)
Windows 64-bit  -  CLAP

This is MERCY with the names scribbled out, for screen recordings. It sounds
exactly like MERCY and works the same; only the names are hidden.

INSTALL
1. Before unzipping: right-click the zip > Properties > tick "Unblock" > OK.
2. Close FL Studio.
3. Copy "Sauce.clap" into  C:\Program Files\Common Files\CLAP\
4. Open FL Studio (2024 or newer): Options > Manage plugins > Find installed plugins.
   It shows up as "Sauce" by slapworx. It installs next to MERCY, it doesn't replace it.

WHAT'S DIFFERENT FROM MERCY
- The name, the era tabs and the era in the spec list are scribbled out.
- Factory presets are called "sauce 01" to "sauce 34" (same sounds, same order as MERCY's).
- Its own user presets (%APPDATA%\Sauce), so your MERCY preset names never show up.
- Bakes go to Documents\Sauce Bakes and are named like loop_sauce_sauce-01.wav.
- In automation the era shows as 01 / 02 / 03.
